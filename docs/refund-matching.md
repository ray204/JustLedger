# 退款关联

退款金额可以小于原支出。原订单号或原交易号明确命中时直接关联；否则在本地按账本、币种、有效支出状态、剩余可退金额、时间与交易线索筛选。

本地规则仅在多项信息支持且候选唯一时选择，例如具体商户与商品一致，或具体商户、付款账户及较近时间相互印证。退款凭证给出原支付金额和原支付时间时，可与支付渠道一起关联没有订单编号的银行记录。这里使用原支付金额，不是退款金额。

同额、平台名称或时间接近本身不能确定原单。明确编号冲突时不采用模糊匹配。

配置 AI 后，可进一步比较筛选后的候选，最多 8 笔；候选过多时保留人工选择，不截取一部分就声称唯一。只发送商户、商品、金额、时间、币种、渠道、可退金额及少量原单线索。提示词只要求返回候选序号，不确定返回 0。解析或调用失败最多重试两次，附上前次输出与错误。

匹配结果在编辑页默认选中，显示商户和金额。点击仍可重新选择，已选项带勾；正在进行的自动匹配不能覆盖人工选择。建议本身不修改已保存账单，保存时再次检查原单状态和累计退款金额。

模型判断仍可能出错，原单信息不足或多笔相近时需要人工核对。没有配置 AI 时本地匹配仍可使用。
