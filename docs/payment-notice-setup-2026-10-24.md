# 真机自动采集配置（2026-10-24）

用户授权开启美团购物自动记账，付款方式可能为微信、支付宝或其他渠道，微信居多。

## 已启用

- JustLedger 通知读取、无障碍屏幕识别、短信接收、悬浮窗权限；应用通知权限原已允许。
- 美团的系统通知原为关闭，已通过系统设置打开。
- 微信、支付宝系统通知权限原已允许。
- 已核对应用白名单包含微信、支付宝、美团，自动保存、自动去重均为开启。
- 已安装三条本地 NOTICE 规则（ID 2、3、4），源码为 `rules/payment-notice.js`。
- 无需激活码、规则订阅或共享 common.js。没有改动用户账单，没有提交 Git。

## 规则范围与限制

| 来源 | 当前可匹配格式 | 依据 |
| --- | --- | --- |
| 美团 | 标题“您已成功付款42.10元”，正文“您的美团订单已支付成功，点击查看详情>” | 项目现有 `test/src/main/resources/test_data_meituan.json` 中的通知样本 |
| 微信 | 标题“微信支付/微信支付凭证”；正文分行包含“支付成功/付款成功”、唯一付款金额、唯一收款方，可带付款方式 | 本次编写的严格格式模板，仅经合成数据验证，尚未采集此手机真实付款通知验证 |
| 支付宝 | 支付通知标题，正文分行包含明确成功状态、唯一付款金额、唯一商户，可带付款方式 | 本次编写的严格格式模板，仅经合成数据验证，尚未采集此手机真实付款通知验证 |

微信通知如果只显示“微信支付凭证”且不带金额，不能据此自动入账。支付宝也不能保证每笔付款都会发出符合模板的通知。美团未透露支付方式时，渠道记录“美团”，付款账户留空，不推测为微信或银行卡。类别没有可靠信息时保留“其他”，用户可在完整编辑器修改。

待付款、退款/退款处理中、转账、失败通知、聊天和多金额歧义均不由这组规则生成支出。**这组规则没有添加退款自动识别或 OCR 解析规则**；开启权限不等于已有全部渠道解析能力。短信接收同理，本次没有添加银行短信规则。

通知缺少交易唯一编号时不编造编号。现有服务器按来源事件防重放；跨来源同额候选进入待核对，避免直接重复计入，但尚不能自动确定微信和美团两条通知必然属于同一笔订单。渠道来源识别和完整跨渠道归并仍需真实数据进一步适配。

未调整电池限制、自启动和任务锁定，不能据此次操作保证长时间后台存活。

## 验证

本地执行 `node --test tests/payment_notice.test.cjs`：3 个测试通过，0 失败、0 跳过。

| Requirement | Evidence |
| --- | --- |
| 支持的成功通知正确提取金额、商户、渠道和时间，不猜测支付账户/交易编号 | `supported_success_notices_preserve_amount_merchant_and_channel` |
| 非付款和歧义通知不产生支出 | `nonpayments_and_ambiguous_notices_do_not_create_expenses` |
| 错误金额、缺失字段和异常数据不猜测入账 | `malformed_amounts_and_payloads_are_rejected_without_guessing` |

采用 code-testing 技能的聚焦单文件流程；当前运行环境没有 code-testing-extensions 语言参考包，使用 Node 内置测试运行器，无额外依赖或报告导出配置。

手机 API `/js/analysis?type=NOTICE&fromAppData=true`：三条成功样本均返回预期金额和渠道、账单 ID 为 0；退款、待付款、隐藏金额、重复金额四条样本均返回 404。该模式不保存账单、不展示已记账弹窗，也没有写入原始采集数据。待确认通知数为 0，首页本月收支仍为 0。

系统回读确认通知监听和无障碍服务均包含 JustLedger，悬浮窗权限为 allow/running，美团通知为 allow。已将手机返回 JustLedger 首页。

**尚未完成真实付款 → 通知采集 → 自动保存 → 确认弹窗的端到端验证**。上述证据仅覆盖权限、规则部署和手机端解析，不应宣称已覆盖所有微信/支付宝付款格式。

## 重装后的规则恢复

规则在手机应用私有数据库中，正常覆盖升级保留；清除应用数据或卸载会丢失。

启动 JustLedger 后执行：

```sh
./scripts/android-local.sh adb forward tcp:52046 tcp:52045
python3 scripts/install-payment-rules.py
./scripts/android-local.sh adb forward --remove tcp:52046
```

脚本仅添加缺失规则，已有同名同来源规则保持原样，不覆盖用户编辑；不会自动启用用户手动停用的规则。
