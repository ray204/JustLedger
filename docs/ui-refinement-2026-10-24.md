# 界面精简与渠道筛选

## 补充：分类图标

新增 26 种本地矢量图标，覆盖餐饮、饮品、交通、服务、购物、居家、水电、服饰、娱乐、医疗、学习、通讯、旅行、美容、宠物、运动、人情、工资、理财、保险、税费、育儿、汽车、转账、退款及其他。设计预览见 `design/category-icons.svg`。

账单行左侧改为 34dp 圆角图标，行高仍为 56dp。按分类名及常见别名匹配，子分类优先，未知分类使用通用图标；列表直接加载本地资源，不依赖网络。编辑器和分类选择器共用默认图标，已有自定义图标仍在这些选择界面中保留。

真机验证了餐饮、交通、服务、购物、咖啡子分类及未知分类的列表显示和滚动复用，检查了编辑器入口。定向清理 ID 30–35 的六笔合成样本后，待确认为 0，月收入/支出恢复 0。构建通过，证据位于 `.local/android/category-icons/`，日志为 `.local/android/logs/category-icons-build.log`。

## 本轮改动

- 账单增加渠道筛选，月份、状态、搜索和渠道共同决定列表及图表范围。微信绑卡付款仍归微信渠道，资金账户单独保留；来源不明确的记录归“其他”，不从资金账户猜测支付平台。
- 消费项改为 56dp 单行：分类、商户、渠道、金额。待核对、不计收支记录优先显示状态；点击编辑，长按删除。日期按组显示，备注、标签、同步标记不再挤占列表。
- 环形图居中，金额放在圆心，图例移到下方；柱状图保留简短收支金额与颜色标记，点击查看日期金额。退款说明仅在有退款时显示，不同币种继续分开统计。
- 编辑器明确显示分类、账户、商户、时间的可点击入口，并保留收支类型、金额、备注等编辑能力。没有预设账户时可直接填写账户名；不再显示分类记忆、资产映射复选框。
- 设置首页收敛为自动记账、记账偏好、屏幕识别、分类与账户、备份与恢复、外观、识别规则、关于。偏好标题 15sp，影响说明 12sp。云备份配置默认折叠。
- 删除设置页的规则更新计划和激活逻辑、关于页的激活链接处理；禁用上游自动规则检查和错误报告上传。移除首页日志/重新引导菜单，保留独立采集设置入口与开源致谢。
- 启动图标重绘为圆润 J 形标记，通知小图标同步替换；启动背景固定深绿，不随夜间模式变浅。矢量源文件：`design/justledger-icon.svg`。

## 验证

设备：Xiaomi 15，Android 16。使用 ADB、UIAutomator、截图和手机本地接口，均为合成测试数据，没有真实付款。

| 场景 | 结果 |
| --- | --- |
| 微信两笔 28 + 36，支付宝两笔 6 + 58，银行一笔 90 | 分别筛选得到 64、64、90，列表与图表一致，全部合计 218 |
| 编辑分类与类型 | 银行测试账单从“居家/支出”改为“其他/收入”，保存后接口读取一致，图表随即更新 |
| 编辑账户与商户 | 无预设账户时直接填写，保存后的账户 `TC`、商户 `SHOP` 与界面一致 |
| 两张自动入账提醒 | 切到第二张 → 去修改显示完整字段 → 取消恢复第二张 → 逐笔确认，队列归零 |
| 设置页与子页面 | 记账偏好、屏幕识别、备份、外观、分类、规则、关于均可进入；付费激活卡片不存在 |
| 设置精简回归 | 首次发现多币种依赖已删除的资产开关导致报错；移除错误依赖后复测通过，并扫描所有设置 XML 依赖 |
| 数据清理 | 定向删除 ID 23–29 的 7 笔测试账单，未清空数据库；待确认 0，月收入/支出恢复 0 |

`:app:assembleDebug` 构建通过，ADB 覆盖安装成功，`git diff --check` 通过。此轮以真机界面和存储校验为主，没有新增或重跑服务端单元测试。
